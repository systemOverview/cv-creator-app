
# CV Creator

This is my first react project. I developed it as a fun project to practice what I've learnt about HTML/CSS/Js and react. It allows a user to create a simple yet a usable CV directly from their browser. I've used react-pdf library for mostly everything about the PDF rendering and generation. 

## Features

- Live preview : You don't need to download the PDF every time you want to see how your CV would look, the live preview section updates on every change to the information you entered. 
- Customizable : Sections are optional, if you do not have work or education experience for example, simply don't put any data in these sections and they will be removed.
- Privacy : Because I developed this before learning backend, your data is only stored on your browser, lack of skill prevents me from stealing them. Very GDPR compliant. [Great Success](https://www.youtube.com/watch?v=sz0vR8gkCgo).
